# Henrri Connect

Henrri Connect est une bibliothèque Python, un SDK, qui facilite l'intégration de votre application avec les services de facturation de Henrri. Encore en cours de développement, elle vise à être utilisée via une publication sur PyPI, permettant ainsi une installation facile avec pip.

## Installation

```bash
pip install henrri-connect
```
